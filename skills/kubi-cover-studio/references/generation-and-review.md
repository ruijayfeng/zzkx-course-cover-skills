# 确认后生成与成图检查

## 调用准备

先核对：真实用户确认对应当前完整方案、课程事实可追溯、输出位置可写、下一个版本未占用。每次调用的范围来自确认和后续明确请求，默认一张首图。

打开本包 `assets/style-references/` 的三张原图，记录如何延续纸色、笔触、颜色和空间。图片基准与来源见 [参考清单](../assets/style-references/MANIFEST.md)。它们是历史画风母版，不代表用户已认可其中的课程内容；不能复制其物象替代本课方案。

生成提示词顺序：已确认主体与关系 → 构图与必要环境 → [风格规范](style-profile.md)中的材质、色彩和笔触 → 留白 → 相关排除项。不得临场改变主体、关键动作、课程对应或引入未确认字符。

默认用纯文字调用当前可用图像生成工具；在 Codex 环境有内置 image_gen 时优先使用并遵守其当时的工具说明。不要编造工具或模型版本。用户要求使用参考图/编辑时，使用真实可访问路径或环境支持的图片引用，并记录实际输入；不把写在提示词里的文件路径当作已向模型传图。

有课程必需字符时，提示词明确允许哪一个字符、在什么位置和载体出现。精确字形可用明确参考或确定性后期排版，不能声称模型产字天然准确。后期添加内容同样属于确认方案与检查范围。

## 保存与技术检查

保存工具实际返回的原图；真实尺寸以文件为准。目标为16:9横图，允许至多1像素边长取整误差（例如1672×941），不通过裁切或拉伸悄悄改变已确认构图。指定交付分辨率时还需检查分辨率；默认不臆造统一像素要求。两套默认是有纸底的完整封面，透明像素须记录并处理，不能把透明背景当成已符合暖白纸底。

可使用 `scripts/prepare_review.py --source 原图 --reference 参考1 参考2 参考3 --out-dir 本课/review/vNN` 生成技术报告、320px缩图与四图对照。脚本需要 Python 3 和 Pillow；课程查询脚本仅用标准库。Codex 可通过工作区依赖工具定位带 Pillow 的运行时；其他环境缺依赖时说明并使用现有图像工具制作等效证据。不要写死作者机器路径。

工具仍在运行或结果不明时，继续跟踪原调用、查询返回位置；不靠重新生成探测结果。图像工具不可用则交付已确认方案、提示词和待生图状态，明确未生成，保持用户资产完整。

## 必须实际查看的证据

打开原图、320px缩图及三参考并排图，再写检查结果。检查表至少包含：

| 项目 | 判断方法 |
|---|---|
| 方案落实 | 逐项对照确认方案：主体、数量、动作、关系、必要符号与表达边界；不是拿提示词证明成图正确 |
| 课程对应 | 确认方案承诺的课程联系在成图是否可见；仅能靠额外解释成立时具体指出，不复用旧 QA 标签 |
| 比例与文件 | 实测尺寸、16:9、可读性、交付格式；原图和副本可追溯 |
| 背景纸色 | 取未着色留白与母版比较：暖白是否延续，有无明显泛黄、泛粉、纯白数字底或脏灰；局部天空/水面不当作纸底 |
| 系列色彩 | 按本风格比较饱和度、主辅色和对比；枯笔重点查是否变成彩色淡彩 |
| 特色质感 | 放大及整体看水墨晕染或枯笔飞白、断墨、纸纤维；不能因“有噪点/纸纹”就判画法正确 |
| 构图与缩图 | 主体和确认关系在320px可辨；上方/右侧题字空间可用，环境不过度抢读，也不强行清空成贴纸 |
| 物象与人物 | 识别特征完整，连接/受力/动作自然；人物眼睛与五官在本图尺度和视角下合理可读，手脚和工具不畸形；写意简化仍应可辨 |
| 意外内容 | 无未确认文字、伪字、水印、Logo或新增叙事主体；明确允许的课程字符逐一核对 |

比例可自动判断，纸色和质感以真实并排视觉观察为主。没有用户指定色值时，不把臆测HEX或整体平均色设为硬门槛；也不把旧主体占比、留白百分比、景物数量当成精确否决阈值。

`qa.md` 写明已查看的文件、确认方案版本、采用参考、各项 PASS/FAIL/UNVERIFIED、可见事实与总体结论。没有看过的证据标未核实；任何关键未核实项不判整体通过。

## 结果处理

- 关键项通过：保存 `QA_PASS`，原图复制到 `final/`，展示图像及真实检查摘要。副本不替代原图，DELIVERED 不代表用户已接受。
- 不通过：保存 `QA_FAILED` 和具体问题，给出改图/重生或改方案建议。默认不自动重生或编辑；用户明确授权后才执行对应次数和范围，版本递增。改变主体或关系须先确认；只修复已确认内容的执行偏差时，用户明确要求修正即可，无需重复确认同一内容。
- 用户预先明确授权有限次数修正时，只在该范围内执行，每张仍先检查再决定下一步；没有授权时不自行设无限重试预算。
- 用户否定已通过图时保留反馈，回到内容或图像环节；用户反馈优先于 Skill 自评。新的成图不得自动加入本包风格母版。
