# 中阶・规范：田园水墨

## 系列基准

- **格式**：16:9横向封面；默认生成插画底图，标题留给排版。
- **背景**：暖白手工纸，轻微自然纤维；明亮柔和，避免强黄旧羊皮纸、纯白数字画布或高反差脏纹理。实际母版中的暖度以三图并排为基准，不任意改成冷白。
- **色彩**：灰蓝水墨、浅苔绿、暖白。竹木、谷物、土壤等可有低饱和自然棕黄，必要的语义色适度保留，避免艳丽大色块。
- **质感**：纸本水墨与淡彩，柔和晕染、透明层次、自然墨色边缘。不能只靠叠纸纹模拟水墨；避免摄影、3D、粗黑卡通轮廓和矢量贴纸感。
- **空间**：可读的主体位于低位或左下，浅层田园纵深；上方或右侧安静，留出题字区域。自然远山、草地、水面、树木、村落按已确认内容使用，环境与主体连贯。
- **层次**：主体及课程选定关系先被读到，环境轻淡承托。既保留自然空气感，也避免背景抢成泛化山水；不规定机械面积或层数。

人物、器物和符号是否出现由用户确认的内容决定；用本系列画法表达。课程必要字符获准出现时逐一核验准确性。默认无标题、说明文字、箭头、网格、签名、水印和边框，确认方案中的必要内容例外须记录。
