# 正字快写课程封面 Skill

两套课程封面制作 Skill：中阶 **田园水墨**、高阶 **枯笔写意**。

先提供画面文字建议，支持自己描述画面；确认完整方案后再出图，检查内容与画风，并保存全部过程资产。

## 安装：把这句话发给 Agent

```text
请按照 https://github.com/ruijayfeng/zzkx-course-cover-skills 中的 INSTALL.md，帮我安装两套课程封面 Skill，并检查安装完整。先不要出图，完成后告诉我怎么开始使用。
```

不需要自己下载压缩包、找隐藏文件夹或运行命令。Agent 负责读取安装说明、安装和检查。本仓库已公开，Agent可以直接读取和安装。

## 开始制作

把交接清单中要做的课程发给 Agent，附上对应的课程 JSON；第一次提供资料后，可以继续指定下一门课。

中阶田园水墨：

```text
使用 $tianyuan-cover-studio，重做中阶“提土旁”（课程ID 10-15，原封面编号299）。课程资料以我提供的JSON为准。先给画面文字建议，我确认完整方案后再出图，把过程和最终资产保存在当前工作区。
```

高阶枯笔写意：

```text
使用 $kubi-cover-studio，重做高阶“单人旁”（课程ID xk-radical-03，原封面编号493）。课程资料以我提供的JSON为准。先给画面文字建议，我确认完整方案后再出图，把过程和最终资产保存在当前工作区。
```

方案都不合适时，直接说“我大概想画……，请结合课程重新整理给我确认”。出图后再确认是否采用；AI 自检通过与用户验收分别记录。

## 两套 Skill

| 路径 | 用途 |
| --- | --- |
| `skills/tianyuan-cover-studio` | 中阶田园水墨：暖白纸底、灰蓝与浅苔绿、水墨淡彩 |
| `skills/kubi-cover-studio` | 高阶枯笔写意：暖白生宣、黑灰墨色、枯笔飞白与断墨 |

每套独立带有课程大纲、三张风格参考图、内容设计、生成检查、归档规范和辅助工具。参考图只校准画风，不代表其中的课程内容已验收。

本仓库只分发制作 Skill，不包含团队待重做名单、NAS 图片库或制作成果。具体任务使用交接人提供的课程 JSON。随包旧大纲中阶为178门；新版JSON新增“竖折撇”（课程ID `9-49`）时，直接读取该课JSON，沿用 `9-49` 命名，不顺延高阶历史编号。

版本：v1.0.0。原有 Skill 内容保持交接快照；新增 GitHub 安装入口。
